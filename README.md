# Mohamed Laabydy — Portfolio

A bilingual portfolio about learning, engineering and building AI systems.

- English: `index.html`
- Français: `fr.html`
- Published address after Pages activation: https://mohamedlaabydy.github.io/

## Publish with GitHub Pages

In Settings → Pages, select **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**. The site needs no build step. `.nojekyll` keeps these static files unchanged.

## Contents

Professional experience at SCOR and OPmobility, learning journey, education, projects, tools, résumé and certifications. Includes an interactive workshop, project filters, English/French navigation and conceptual technical illustrations.
